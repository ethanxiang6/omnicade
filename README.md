## Download

1. Open the **Releases** page of this repo.
2. Under the newest release, download **index.html**.
   - Chrome and Edge may warn that HTML files can harm your computer. Choose **Keep** — it's a web page, nothing gets installed.
3. Move it somewhere you'll keep it, like your Desktop. Downloads folders get cleared.

## Run

Double-click the file. It opens in your browser and the site loads.

If you see code instead of the site, it opened in a text editor. Right-click the file → **Open with** → Chrome or Edge.

## If it won't let you in

- **"Out of date"** — you're on an older copy. Download index.html from Releases again and delete the old one.
- **"Waiting for approval"** — your account was created and an admin has to approve it. Nothing else to do on your end.
