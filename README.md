# Omni

A single HTML file: a 200-game arcade and website embedder.
Nothing installs and there's no website to visit — the file is the app.

## Download

1. Open the [latest release](https://github.com/ethanxiang6/omnicade/releases/latest).
2. Download the `.html` file attached to it. It's named after the build.
   - Chrome and Edge may warn that HTML files can harm your computer.
     Choose **Keep** — it's a web page, nothing gets installed.
3. Move it somewhere you'll keep it, like your Desktop. Downloads folders get
   cleared.

## Run

Double-click the file. It opens in your browser and the site loads.

If you see code instead of the site, it opened in a text editor. Right-click the
file → **Open with** → Chrome or Edge.

## If it won't let you in

- **"Out of date"** — you're on an older build. Open the latest release again,
  download the new file, and delete the old one. Sign-in stays locked until you do.
- **"Waiting for approval"** — your account was created and has to be approved
  before you can get in. Nothing else to do on your end.
